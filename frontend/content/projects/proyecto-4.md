# Asignación de Líneas de Crédito (Finanzas)

## Descripción
Sistema multiagente para predicción histórica y procesamiento documental, reduciendo el uso de recursos humanos en un **50%**.

## Tecnologías Utilizadas
- LangChain
- Sistemas Multiagente
- Machine Learning
- Azure OpenAI
- Python

## Impacto
- ✅ Reducción del 50% en recursos humanos
- ✅ Predicción automática basada en históricos
- ✅ Procesamiento inteligente de documentos
- ✅ Toma de decisiones automatizada

## Rol
Diseño e implementación de arquitectura multiagente, desarrollo de modelos predictivos y orquestación de agentes.
