# Agente de IA para Análisis Inmobiliario - MAIA (Público)

## Descripción
Agente inteligente generador de **insights automatizados** para la selección de inmuebles a comprar. Los usuarios pueden subir documentos requeridos para la evaluación inmobiliaria y el agente analiza automáticamente los requerimientos, proporcionando **sugerencias precisas y atractivas** basadas en IA para la toma de decisiones.

El principal desafío de esta solución fue trabajar con **documentos escaneados o mal digitalizados**, por lo que se utilizó un **modelo multimodal** para realizar la lectura y extracción de información de forma precisa, superando las limitaciones del OCR tradicional.

## Tecnologías Utilizadas
- GPT-4o
- RAG (Retrieval-Augmented Generation)
- Automatización de documentos
- Python
- Análisis multimodal

## Impacto
- ✅ Automatización completa del análisis inmobiliario
- ✅ Procesamiento inteligente de documentos legales y técnicos
- ✅ Insights precisos para toma de decisiones
- ✅ Reducción significativa del tiempo de evaluación
- ✅ Sugerencias personalizadas basadas en requisitos

## Rol
Desarrollo completo del agente de IA, implementación de RAG para análisis documental, diseño de la lógica de evaluación y generación de insights automatizados para la selección inmobiliaria.
