# Digitalización de Recetas Médicas (Salud)

## Descripción
Interpretación automática de recetas y órdenes de laboratorio usando Azure Cognitive Services (OCR y LLM), reduciendo un **80%** el tiempo operativo.

## Tecnologías Utilizadas
- Azure Cognitive Services
- OCR Avanzado
- GPT-4
- Python
- Flask

## Impacto
- ✅ Reducción del 80% en tiempo operativo
- ✅ Digitalización automática de recetas manuscritas
- ✅ Interpretación inteligente de órdenes médicas
- ✅ Integración con sistemas hospitalarios

## Rol
Desarrollo del sistema de OCR y procesamiento de lenguaje natural para interpretación de documentos médicos.
