# Chatbot Agrícola (Cultivos Peruanos)

## Descripción
Desarrollo de un chat conversacional con GPT-4o-mini (fine-tuning) y RAG híbrido para diagnóstico agrícola y recomendaciones expertas sin intervención humana.

## Tecnologías Utilizadas
- GPT-4o-mini
- Fine-tuning
- RAG Híbrido
- ChromaDB
- Flask
- React

## Impacto
- ✅ Diagnóstico automático de cultivos
- ✅ Recomendaciones expertas en tiempo real
- ✅ Dashboard web responsivo
- ✅ Optimización de modelos mediante fine-tuning

## Rol
Desarrollo completo del chatbot, fine-tuning del modelo, implementación de RAG y desarrollo del dashboard web.
