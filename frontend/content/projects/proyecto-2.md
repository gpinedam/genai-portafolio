# Verificación de Documentos Legales (Finanzas)

## Descripción
Validación automática de documentos legales en Azure contra fuentes públicas, reduciendo tiempos de verificación de **semanas a minutos** (ahorro del 99% del tiempo).

## Tecnologías Utilizadas
- Azure Document Intelligence
- Azure Cognitive Services
- Python
- REST APIs
- Cosmos DB

## Impacto
- ✅ Reducción del 99% en tiempo de verificación
- ✅ Validación contra fuentes públicas en tiempo real
- ✅ Eliminación de procesos manuales
- ✅ Mayor precisión en verificaciones

## Rol
Arquitectura de la solución, integración con APIs gubernamentales y desarrollo del pipeline de validación.
